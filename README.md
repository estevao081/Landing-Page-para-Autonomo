## 🚀 Sobre o Projeto

Este projeto é uma **landing page profissional** criada para um personal trainer fictício, com o objetivo de:

- Apresentar serviços de forma clara e segmentada
- Gerar leads por meio de formulário de contato
- Transmitir autoridade (CREF, experiência, depoimentos)
- Funcionar perfeitamente em **mobile, tablet e desktop**

### 🧠 Conceito Visual
- Cores: Preto (`#0a0a0a`) e verde-limão (`#e8ff3a`) — contraste moderno e energético
- Tipografia: `Bebas Neue` para títulos (impacto) e `DM Sans` para textos (leitura fluida)
- Elementos: cards com hover, animações suaves, badges e ícones expressivos

---

## 🧱 Estrutura da Página

| Seção          | Descrição |
|----------------|-----------|
| `#hero`        | Chamada principal com CTA e estatísticas |
| `#sobre`       | Apresentação do profissional e credenciais |
| `#servicos`    | Cards com modalidades de atendimento |
| `#vantagens`   | Diferenciais numerados (1 a 8) |
| `#depoimentos` | Provas sociais com depoimentos reais |
| `#contato`     | Formulário + informações de contato |
| `footer`       | Redes sociais e créditos |

---

## ⚙️ Funcionalidades

✅ **Menu mobile responsivo** com hambúrguer  
✅ **Scroll suave** para seções internas  
✅ **Botão "voltar ao topo"** que aparece ao rolar  
✅ **Animações de entrada** com `IntersectionObserver`  
✅ **Formulário funcional** com validação básica e feedback visual  
✅ **Design System com variáveis CSS** (fácil de customizar)  
✅ **Deploy facilitado** com `netlify.toml` (SPA fallback)

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** semântico
- **CSS3** (Flexbox, Grid, variáveis, animações)
- **JavaScript puro** (ES6+)
- **Google Fonts** (`Bebas Neue` + `DM Sans`)
- **Netlify** (configuração de redirects SPA)
